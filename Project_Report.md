# Banking Customer Insights Dashboard

## Introduction

The Banking Customer Insights Dashboard is a Power BI project designed to analyze customer banking behavior, deposits, loans, and financial performance metrics.

The dashboard provides a comprehensive view of banking operations through interactive visualizations, enabling users to identify trends, evaluate customer segments, and monitor key financial indicators.

---

## Objectives

* Analyze customer loan and deposit patterns.
* Monitor key banking performance indicators.
* Evaluate customer behavior across different demographics.
* Identify trends in lending and deposits.
* Support business decisions through data visualization.

---

## Tools Used

* Power BI
* Microsoft Excel
* DAX
* Data Modeling

---

## Dashboard Pages

### Home Dashboard

Provides an overview of key banking metrics including clients, loans, deposits, savings accounts, and checking accounts.

### Loan Analysis

Analyzes loan performance by:

* Banking Relationship
* Occupation
* Nationality
* Income Band
* Gender

### Deposit Analysis

Provides insights into:

* Deposit Distribution
* Savings Accounts
* Checking Accounts
* Customer Segmentation
* Banking Relationships

### Summary Dashboard

Presents a consolidated overview of important financial metrics for management reporting.

---

## Key Performance Indicators

* Total Clients
* Total Loan Amount
* Total Deposit Amount
* Savings Accounts
* Checking Accounts
* Business Lending
* Credit Card Balance
